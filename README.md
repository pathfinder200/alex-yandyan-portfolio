# Alex Yandyan — Sketchbook Portfolio

A hand-drawn, sketchbook-style design portfolio. A rubber-chicken cursor that floats, spins and squeaks; works that explode into full case studies.

**Live site:** https://pathfinder200.github.io/alex-yandyan-portfolio/

## Structure
- `index.html` — the whole site (HTML, CSS and JS in one file)
- `work/` — project images and videos, one folder per case study
- `chicken.png` — the cursor
- `alex.jpg` — portrait
- `Alex_Yandyan_CV.pdf` — downloadable CV

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
